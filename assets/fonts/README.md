# Fuentes

Subsets `latin` y `latin-ext` de las familias variables:

- **Fraunces** — display (títulos). SIL Open Font License 1.1 · https://fonts.google.com/specimen/Fraunces
- **Inter** — texto e interfaz. SIL Open Font License 1.1 · https://fonts.google.com/specimen/Inter

Están auto-alojadas a propósito: evitan una conexión extra a un CDN externo
(más rápido en 4G) y no envían datos del cliente a terceros.
Ambas licencias permiten el uso web y la redistribución de los archivos.
